Discord Fonts: Cool Text Styles for Your Name & Messages (Copy and Paste)

Published November 8, 2026

Discord fonts let you make your username, nickname, server name and messages look different from the plain default text. Discord has no built-in font picker, so the usual trick is to use Unicode text styles — special characters that look like cursive, gothic, bold or bubble letters. Tap any style below to copy and paste it into Discord.

How do Discord fonts work?

Discord displays whatever characters you type. The Unicode standard includes whole alphabets of decorated letters (originally meant for mathematics), and they look like different fonts. They are not real font files, so there is nothing to install and nobody else needs anything special to see them — in most cases. Where can you use fonts on Discord?

  • Display name and server nickname — the name people see next to your messages
  • Server names and channel descriptions
  • Your About Me and custom status
  • Messages — for a short emphasis; long paragraphs in decorated letters are tiring to read

Discord also has its own Markdown formatting — typing **text** for bold or *text* for italics — which works in messages but is not the same as a different font. Unicode styles are what change the actual letter shapes, so they also work in names and statuses where Markdown doesn't.

Tips for using Discord fonts well

  • Keep names short. Decorated letters are wider and harder to read in long names.
  • Mind readability. Some styles are hard to read for people using screen readers or small screens, so don't use them for important information.
  • Be searchable. Friends may find it hard to search for a decorated name, so keep a plain version of your name in your bio.
  • Check on mobile. Preview your name on your phone before you commit to it.

The problem with Discord font generators

Most people find these styles on websites: open the site, type your text, copy, switch back to Discord, paste. Every time. That gets old fast, and it adds a few more problems:

  • Constant app switching every time you want a styled message
  • Boxes instead of letters if a symbol isn't supported on someone's device
  • No preview inside the actual chat, so you only see how it looks after you've pasted it

Discord fonts FAQ

How do I change my font on Discord?

Discord does not offer a font setting for messages. You change how text looks by using Unicode font styles, which you can copy from a generator or type directly with a font keyboard such as Cool Fonts Keyboard.

How do I get a cool font for my Discord name?

Go to your profile settings, open the display name or server nickname field, and paste or type a styled name like the examples above.

Can I use Discord fonts on mobile?

Yes. On Android, a font keyboard lets you type styled text directly in the Discord app.

Are Discord fonts the same as Markdown?

No. Markdown adds formatting like bold or italics to normal letters in messages. Discord fonts replace the letters themselves with styled Unicode characters.

Why do some Discord font letters show as boxes?

A device that lacks a font for that symbol shows an empty box. Common styles like bold and cursive usually display fine, but test your name before settling on it.
